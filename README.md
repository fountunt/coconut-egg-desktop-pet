# 🥥 Coconut Egg Desktop Pet

**AI Desktop Pet - Coconut Egg** / AI桌宠椰子蛋

A cute animated desktop companion that walks around your screen.

## Features

- 🚶 Walks freely across your desktop
- 👁️ Blinks and shows various expressions
- 💬 Speech bubbles with random phrases
- 😊 Multiple moods: happy, sleepy, surprised, love, derp
- 🎚 Adjustable opacity and walking frequency
- 📌 Always-on-top mode
- 💾 Auto-saves position and settings

## Usage

Double-click `CoconutPet.lnk` on your desktop, or run:
```
pythonw D:\CoconutPet\DesktopPet.pyw
```

## Requirements

- Python 3.8+
- tkinter (built-in)
